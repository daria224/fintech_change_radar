# Радар на вашем компьютере

GitHub и развёртывание в Coolify для этого режима не нужны. Docker Desktop запускает три контейнера: отдельную локальную базу, сборщик/анализ и Telegram-бота. База сохраняется в томе `fintech-radar-local_local_pgdata`; остановка через `STOP_LOCAL.cmd` данные не удаляет.

## Начать

1. Запустите Docker Desktop.
2. Один раз остановите **ваш прежний ресурс** в Coolify, чтобы его bot и worker не работали одновременно с локальной версией. Ресурс и том базы сохраните. Для одного токена Telegram нужен один активный экземпляр бота; расходы двух независимых установок не объединяются.
3. Откройте `SETUP_LOCAL.cmd` в этой папке. Вставьте токен существующего бота и ключ OpenRouter в появившееся окно. Ввод скрыт. Значения сохраняются только в `.env.local`, который исключён из Git и Docker-образа. Enter сохраняет прежний ключ. Подтвердите, что прежний серверный экземпляр остановлен.
4. Откройте `START_LOCAL.cmd`. Дождитесь успешного запуска контейнеров.
5. Напишите `/start` боту @fintech_change_radar_desk_bot и затем `/status`. Локальная установка использует отдельную базу: прежняя серверная история и подписчики автоматически в неё не копируются. Для вас подписка создаётся командой `/start`; перенос остальных подписчиков возможен отдельно из резервной копии.

Лента: **http://127.0.0.1:18080/** на этом компьютере. Доступны реальные карточки после анализа моделью. По умолчанию кнопка Telegram Mini App отключена: ей требуется публичный HTTPS-адрес. Сами личные сообщения и сводки работают без публичного адреса и без входящих портов роутера.

Если пока нет ключей или сервер ещё работает, откройте `PREVIEW_LOCAL.cmd`: сбор и локальная лента запускаются без Telegram и платной модели. После настройки `START_LOCAL.cmd` заменит режим просмотра рабочими контейнерами.

## Ежедневная работа

- Сбор — каждые 6 часов, сводка — в 09:00 МСК. Первый сбор является историей и не рассылается как свежие новости.
- Компьютер, интернет и Docker Desktop должны работать. Во сне и при выключении сводки не отправляются. Если компьютер проснулся после 09:00 в тот же день, сводка будет сформирована при возобновлении работы; пропущенные дни задним числом не рассылаются.
- Контейнеры настроены на перезапуск при запуске Docker Desktop. Автозапуск Docker Desktop вместе с Windows и настройки сна можно настроить по вашему желанию; автоматически они не меняются.
- Остановка: `STOP_LOCAL.cmd`. Повторный запуск: `START_LOCAL.cmd`.
- Лимит OpenRouter — $1 за день Москвы, включая историю. Сервер в этом режиме не нужен; модель по-прежнему оплачивается через ваш OpenRouter.
- Не удаляйте Docker-том `fintech-radar-local_local_pgdata`: в нём история, подписка и учёт бюджета. Не публикуйте и не присылайте `.env.local`.
